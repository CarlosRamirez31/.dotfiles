# Configuración activa de Hyprland

La documentación completa, los atajos y la configuración de monitores están en
[`components/hyprland/README.md`](../../../README.md).

Este directorio es el árbol enlazado a `~/.config/hypr`; no almacena secretos ni
ajustes propios de una máquina. Usa `local.lua` para esos cambios.
