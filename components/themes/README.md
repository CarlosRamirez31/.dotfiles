# Themes

Instala el cursor `Bibata Modern Classic` y los iconos Oranchelo usados por
Hyprland, Hyprlock, HyprPanel y aplicaciones GTK. Ambos vienen del AUR; el
instalador reutiliza `paru` o `yay` y crea `yay` solamente si hace falta.

```bash
./install.sh themes
```

Los nombres del cursor y su tamaño se exportan desde el módulo `uwsm`.
