# Atajos configurados

`Alt` es la tecla modificadora principal del escritorio. `Super` es la tecla
Windows. Estos son los atajos configurados actualmente, agrupados por función.

## Aplicaciones y sesión

| Atajo | Acción |
| --- | --- |
| `Alt+Enter` | Abrir terminal. |
| `Ctrl+Alt+T` | Abrir terminal. |
| `Alt+Space`, `Alt+D`, `Alt+F2` | Abrir lanzador de aplicaciones. |
| `Alt+Tab` | Abrir selector de ventanas. También permite volver a una ventana minimizada. |
| `Alt+B` | Abrir Firefox. |
| `Alt+E` | Abrir Yazi, el gestor de archivos en terminal. |
| `Ctrl+Alt+E` | Abrir Thunar. |
| `Alt+W` | Elegir fondo de pantalla. |
| `Alt+C` | Abrir historial del portapapeles. |
| `Ctrl+Shift+B` | Bloquear la sesión. |
| `Alt+Shift+E` | Cerrar Awesome. |

## Ventanas

| Atajo | Acción |
| --- | --- |
| `Alt+Q` | Cerrar la ventana enfocada. |
| `Alt+F9` | Minimizar la ventana enfocada. |
| `Alt+V` | Alternar la ventana enfocada entre mosaico y flotante. |
| `Alt+Shift+=` | Aumentar el tamaño de una ventana flotante. |
| `Alt+Shift+-` | Reducir el tamaño de una ventana flotante. |
| `Alt+H/J/K/L` | Mover el foco a izquierda/abajo/arriba/derecha. |
| `Alt+←/↓/↑/→` | Mover el foco a izquierda/abajo/arriba/derecha. |
| `Alt+Shift+H/J/K/L` | Intercambiar la ventana enfocada a izquierda/abajo/arriba/derecha. |
| `Alt+Shift+←/↓/↑/→` | Intercambiar la ventana enfocada a izquierda/abajo/arriba/derecha. |
| `Ctrl+Alt+H/L` | Reducir/aumentar el ancho relativo de la columna actual. |
| `Ctrl+Alt+J/K` | Reducir/aumentar el espacio relativo de la ventana actual. |
| `Ctrl+Alt+←/→` | Reducir/aumentar el ancho relativo de la columna actual. |
| `Ctrl+Alt+↓/↑` | Reducir/aumentar el espacio relativo de la ventana actual. |

## Escritorios (tags)

| Atajo | Acción |
| --- | --- |
| `Alt+1` a `Alt+4` | Ir al tag 1, 2, 3 o 4. |
| `Alt+Shift+1` a `Alt+Shift+4` | Mover la ventana enfocada al tag indicado e ir a él. |

## Capturas, color y grabación

| Atajo | Acción |
| --- | --- |
| `Impr Pant` | Captura de toda la pantalla. |
| `Alt+Impr Pant` | Captura de un área. |
| `Alt+Shift+S` | Captura de un área. |
| `Alt+Shift+R` | Grabar un área de pantalla. |
| `Alt+Shift+C` | Abrir selector de color. |

## Teclado, audio y multimedia

| Atajo | Acción |
| --- | --- |
| `Super+K` | Alternar entre teclado US y Español Latinoamericano. |
| Clic en `us`/`latam` de la barra | Alternar entre teclado US y Español Latinoamericano. |
| Teclas de volumen | Subir, bajar o silenciar el volumen. |
| Tecla de silenciar micrófono | Silenciar o activar el micrófono. |
| Teclas de brillo | Subir o bajar brillo. |
| Reproducir/Pausar, Siguiente, Anterior | Control multimedia. |

## Terminal Alacritty

| Atajo | Acción |
| --- | --- |
| `Ctrl+Backspace` | Borrar la palabra anterior en Zsh. |
| `Shift+←/→` | Seleccionar caracteres en la línea de comandos. |
| `Ctrl+Shift+←/→` | Seleccionar palabras en la línea de comandos. |

## Yazi (después de abrirlo con `Alt+E`)

| Atajo | Acción |
| --- | --- |
| `Enter` | Abrir el archivo o directorio seleccionado. |
| `Shift+Enter` | Abrir o confirmar el archivo. |
| `G D` | Ir a Descargas. |
| `G P` | Ir a Imágenes. |
| `G H` | Ir a tu carpeta personal. |
