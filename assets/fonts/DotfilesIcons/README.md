# Dotfiles Icons

U+E000 contains the Hack The Box mark from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/hackthebox.svg), under CC0 (see LICENSE.md).
The original SVG is bundled. Polybar colors the glyph HTB green (#9FEF00).

Regenerate the bundled TTF with `python build.py` in a Python environment with `fonttools` installed. Font tools are only needed to rebuild, not to install or use the font.
