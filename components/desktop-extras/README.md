# Desktop extras

Completa el uso diario con Firefox, KeePassXC, Btop, grabación Wayland,
selector de color y papelera desde terminal.

## Atajos y comandos

- `Alt+B`: Firefox.
- `Alt+Shift+R`: seleccionar región e iniciar/detener grabación.
- `Alt+Shift+C`: seleccionar un color y copiarlo.
- `btop`: CPU, memoria, procesos, red y discos.
- `keepassxc`: administrador local de contraseñas.
- `trash-put ARCHIVO`: mover a papelera; `trash-restore`: recuperar.

Las grabaciones se guardan en `Videos/Recordings`. No se reemplaza `rm`, para
que scripts y herramientas con comportamiento Unix sigan siendo predecibles.
