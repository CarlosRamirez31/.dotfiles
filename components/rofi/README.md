# Rofi

Lanzador de aplicaciones Wayland con el mismo color, tipografía y redondeado
del escritorio. El wrapper abre cada aplicación seleccionada dentro de la
sesión UWSM correcta.

```bash
./install.sh rofi
dotfiles-app-launcher
```

Atajos: `Super+Space`, `Super+D` o `Alt+F2`. El tema está en
`.config/rofi/theme.rasi`.
